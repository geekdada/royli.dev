models.dev 是一个很棒的网站，但是随着模型越来越多网站的性能变得越来越糟糕。这个命令行工具读取 models.dev 维护的数据库，提供模糊搜索和信息查看。

<LinkPreview url="https://github.com/geekdada/models-dev-cli" />

## 安装

```bash
brew install geekdada/tap/models
models
```

## 使用

软件打开之后即可开始在供应商和模型中进行混合搜索。

<MDXImage src="./resources/models-2.png" alt="搜索模型和供应商" />

同时命令行也提供了模糊搜索的功能。模糊搜索是基于供应商名称和模型名称进行模糊搜索。

<MDXImage src="./resources/models-3.webp" alt="模糊搜索" />
